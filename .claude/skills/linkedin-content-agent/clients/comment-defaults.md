# Default rules for engagement comments (all clients)

- Default to a positive tone. Don't wait to be asked to "make it positive" — write the first draft that way. Positive means encouraging/uplifting framing, not just agreeing; it can still make a sharp point.
- Keep comments short — one line/one sentence unless asked for more.
- Never lift exact phrases or lines from the post being commented on. Paraphrase and build a genuinely separate angle instead of restating the post's own point.
- Don't just summarize the post's argument back to it — apply one piece of it to a concrete scenario the post doesn't cover, or add an original observation.
- Weave in client-specific keywords (see the relevant client file) naturally, not by repeating the same one or two words every time — vary the vocabulary.
